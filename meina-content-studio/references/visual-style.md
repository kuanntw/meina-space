# Visual style and cover prompts

用于封面、配图、图像生成 Prompt 或视觉规范。

## Default visual system

奶油米白、暖橙色、浅橙色、焦糖棕、浅咖色；明亮柔和，有轻微光晕，温暖商业插画感，专业但不冷硬，有轻科技感但不赛博。符合中国大陆小红书、抖音高质量职场知识类封面审美。画面精致、有质感、留白足。

避免深色压迫、冷蓝主调、赛博朋克、霓虹科技风、复杂机械背景、廉价卡通、过多装饰、拥挤、字太多、大量小字、过度写实导致像特定真人。

## Character: 美娜

亚洲女性，约30至40岁，成熟、温柔、知性、自信，有职业感但不强势。中长深棕色头发，自然蓬松、轻微卷度，不夸张大波浪。常穿米色或浅咖色西装外套，白色或奶油色内搭。神态温和但有判断力，可微笑、思考、观察、倾听或冷静分析。不要复制任何真人。保持气质一致，但允许服装、姿势、发型细节和场景变化，避免每张完全一样。

若用户要求封面不要人物，服从。

## Elements

按主题少量加入 HR、AI、数据、流程、组织结构、对话气泡、会议、文件、电脑、权限锁、人机协作、团队关系、决策路径、风险提示、职场人物剪影。元素辅助主题，不抢人物和标题。

## Text and layout

文字用简体中文；标题字少、清晰、手机端可辨识；可用少量暖橙突出关键词；不放长篇正文；如果图像模型文字不可靠，设计标题区和留白，建议后期排版加字。

构图按用户比例：1:1、3:4、4:3、9:16、16:9 等。未指定时按平台选择：小红书常用1:1或3:4；横版文章封面常用4:3；视频封面按用户要求用9:16或16:9。四周保留10%—15%安全裁切空间，人物和标题不贴边，画面干净，主视觉明确，不塞入文章全部观点。

## Cover Prompt fields

生成封面 Prompt 时包含：图片比例、主标题、可选副标题、人物设定、场景、构图、配色、图形元素、光线、字体和排版方向、安全裁切空间、需要避免的元素。标题过长时主动建议缩短。
