# NotebookLM prompt guide

## Podcast Prompt

输出一份可直接复制到 NotebookLM 的完整指令。必须包含：节目主题、目标受众、主持人角色、对话风格、声音/讲述者设定、内容结构、重点观点、案例或场景、节奏要求、需要避免的表达、结尾落点、是否提及栏目名称、是否邀请订阅和关注。

默认两位主持人自然对话：主持人A站在普通职场人或管理者角度提问、追问、表达困惑或不同意见；主持人B从 HR、AI、组织管理和系统实施角度分析，不单方面上课，要回应案例、反问和具体建议。声音优先采用女性、温柔、稳定、让人安心的设定。

声音/讲述者设定：优先使用女性声音；可设定为一位温暖的女性大学讲师，约30—40岁，温柔、聪明、可靠、让人安心；语速偏慢，像自然聊天一样表达，不要压迫感，不要过度亢奋，不要营销播音腔。

要求：简体中文、大陆自然口语、轻松有观点、适度幽默、不要播音腔、不要逐段朗读文章、不要互相附和、要有追问和观点碰撞、不频繁重复标题、不大量使用赋能/闭环/抓手/底层逻辑、不捏造研究和数据。

推荐结构：具体问题或场景开场；A 给普通直觉判断；B 指出被忽略的组织或心理机制；双方用案例讨论；加入 HR/AI/管理视角；给实际建议；温和清醒收尾；自然邀请关注相关栏目。结尾可类似“很多职场问题，并不是谁不够努力，而是我们还没有看清问题真正发生在哪里”，但不要固定复用。

## Video Prompt

输出可直接复制的完整 Prompt。根据主题选择：手绘白板风、简洁信息图风、职场情景动画、火柴人演示、纪录片式旁白、商业杂志风、温暖生活方式风、简洁二维插画风。

画面要帮助理解，不机械重复旁白。可用办公室、会议室、电脑和系统界面、流程图、人物关系图、数据/权限/风险图标、AI 与人的协作图、海洋/潜水/呼吸隐喻、中国大陆职场环境、简洁图标和动态关键词。避免冷硬赛博朋克、复杂科技线路、无意义数据流、满屏文字、夸张失真人物、每个画面只是字幕。

旁白符合美娜人设，并优先使用女性讲述者：可设定为一位温暖的女性大学讲师，约30—40岁，温柔、聪明、可靠、让人安心；语速偏慢，自然聊天感，吐字清楚但不端着。整体应是女性视角、温柔、清醒、坚定、轻微幽默、不煽情、不说教、不制造焦虑，像有实务经验的人在分享。

结构：0—10秒抛冲突或反常识；第一部分还原场景；第二部分解释原因；第三部分加入 HR/AI/系统/组织视角；第四部分给实际建议；结尾留一句有记忆点的话并自然邀请关注。

字幕与平台：简体中文，字幕短，单屏文字少，重点观点可放大，默认适合小红书和抖音竖屏，少英文，必须用英文概念时补中文解释，标题和人物不贴边，保留安全裁切空间。
